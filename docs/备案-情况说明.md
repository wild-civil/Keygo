## 一、小程序具体从事的业务 / 服务说明

本小程序（微信小程序）名称为“BLE车钥匙”，是 KeyGo 蓝牙车锁硬件设备的配套控制客户端，主要面向已拥有 KeyGo 蓝牙车锁硬件设备的个人用户，提供基于蓝牙低功耗（BLE）的近场车辆控制服务。小程序所有控制指令均由手机蓝牙与用户手中的实体硬件设备（CH582M 蓝牙芯片）点对点通信完成，不通过服务器中转，未提供面向公众的互联网信息服务（如信息发布、内容交易等）。

### 1. 主要服务功能
（1）**设备扫描与连接**：通过手机蓝牙扫描附近的 KeyGo 蓝牙设备，列表展示设备名称与信号强度，用户选择后建立蓝牙连接。
（2）**车辆控制**：连接成功后，用户可通过界面按钮向设备下发解锁、锁车、后备箱/骑行（汽车 / 电瓶车双模式第三键）等控制指令。
（3）**信号强度（RSSI）显示**：实时显示设备蓝牙信号强度，辅助用户判断车辆与手机的距离。
（4）**参数配置**：用户可设置解锁 / 锁车信号阈值、确认次数、采样间隔等参数，并下发至设备，用于“舒适进入”（靠近自动解锁）功能。
（5）**设备绑定与鉴权**：首次使用通过绑定码（bind code）将手机与设备建立信任关系，后续连接需通过挑战应答鉴权，保障控制安全。
（6）**使用帮助**：提供设备使用说明、故障排查等静态图文帮助。

### 2. 涉及的用户权限及用途
- **蓝牙权限**：用于设备扫描、连接与控制，是小程序核心功能所需。
- **位置权限（scope.userLocation）**：微信平台在部分场景下要求开启位置权限方可进行蓝牙设备扫描，仅用于本地蓝牙扫描与极速模式下的停车距离判断，不上传、不存储用户位置信息。

- 不提供用户发布内容（UGC）、论坛、社交、直播、短视频等信息服务。
- 不含在线支付、电商交易、虚拟货币、游戏等增值业务。
